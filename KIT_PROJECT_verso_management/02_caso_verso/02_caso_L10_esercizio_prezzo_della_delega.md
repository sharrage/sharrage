# L10 · Esercizio · Il prezzo della delega (SIM)

*In coppia o in stanza. Quando deleghiamo qualcosa all'AI scambiamo autonomia e libertà con produttività. Questo esercizio rende visibile lo scambio, gesto per gesto.*

**Consegna.** Scegliete tre gesti: dal vostro flusso n8n oppure dai dieci gesti di Vèrso (`L10_dieci_gesti_SIM.md`). Per ognuno compilate una riga.

| Gesto | Che chiave date all'AI | Che cosa guadagnate | Che cosa cedete | Che cosa rischiate | Che cosa non volete smettere di saper fare | Chi decide la chiave (la A) |
|---|---|---|---|---|---|---|
| | piccola · media · grande | minuti a settimana, velocità, coerenza | il modo, il ritmo, il giudizio | | | |
| | | | | | | |
| | | | | | | |

**Le tre chiavi.**
- **Piccola:** l'agente prepara, invia una persona.
- **Media:** l'agente compila e organizza, una persona controlla.
- **Grande:** l'agente agisce da solo, dove tutto è reversibile e misurato.

**La domanda finale, una per gruppo:** quanta libertà siete disposti a cedere, e in cambio di che cosa? Scrivetela in una frase che l'AD capirebbe.

*Numeri utili dal caso (SIM): 600 richieste a settimana nel picco; 9 minuti a richiesta tutto a mano; 3 minuti di controllo a bozza se si approva tutto; due persone, circa 80 ore di presenza a settimana.*
